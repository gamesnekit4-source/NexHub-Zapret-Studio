# ⚡ NexHub — Zapret DPI Studio

Современная, быстрая и стильная графическая оболочка для обхода замедлений Discord и YouTube на Windows (на базе WinDivert / winws).

---

## 💡 Чем полезен проект?

Консольные утилиты обхода блокировок часто требуют запуска через терминалы и командную строку. **NexHub** решает эту проблему:
- Предоставляет удобный визуальный интерфейс управления без открытых черных консольных окон.
- Позволяет переключать пресеты запуска (.bat) в один клик.
- Защищает от зависаний драйвера благодаря нативному Win32-контроллеру процессов.
- Дает полную свободу персонализации внешнего вида (OLED, Cyberpunk, неоновое свечение, темы).

---

## ✨ Возможности

- 🚀 **Управление в 1 клик:** Быстрый старт и остановка службы фильтрации пакетов.
- 📁 **Автопоиск пресетов:** Автоматически находит все bat-файлы в вашей папке Azapret (`general.bat`, альтернативные пресеты и т.д.).
- 🎨 **Студия кастомизации:**
  - 8 готовых палитр + произвольный выбор цвета (Color Picker).
  - 4 стиля темы: *Midnight*, *OLED Pure Black*, *Cyberpunk*, *Slate*.
  - 4 типа градиентов фона: *Radial*, *Aurora*, *Linear*, *Flat*.
  - Регулировка интенсивности свечения и размытия карточек (Backdrop Blur).
- ⚡ **Высокая стабильность:**
  - Мгновенная остановка процесса через системный Win32 API `TerminateProcess`.
  - Асинхронный запуск без фризов интерфейса.
  - Изолированный профиль кэша браузера для каждого сеанса.
- 🖥️ **Полноэкранный режим:** Поддержка клавиши `F11` и кнопки в шапке.
- 🌐 **Мультиязычность:** Переключение между русским и английским языками (RU / EN).

---

## 🛠️ Требования

- Windows 10 / 11 (64-bit)
- Установленный пакет Azapret с файлом `winws.exe` (например, в `D:\Azapret-discord-youtube-1.10.3`)
- Права Администратора (необходимы для инициализации сетевого драйвера WinDivert)

---

## 🚀 Установка и запуск

### Вариант 1. Готовый файл (Для пользователей)
1. Скачайте **`NexHub.exe`** из раздела Releases.
2. Запустите от имени Администратора.
3. Выберите нужный пресет и нажмите **«Запустить пресет»**.

### Вариант 2. Запуск из исходников (Для разработчиков)
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/NexHub.git
   cd NexHub
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите проект:
   ```bash
   python app.py
   ```

## 📦 Сборка в .exe

Для сборки автономного исполняемого файла запустите:
```bash
python build.py
```
Собранный файл появится в каталоге `dist/NexHub.exe`.
